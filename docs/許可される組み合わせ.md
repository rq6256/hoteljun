# 許可される組み合わせ（最安エンジンの探索文法）

既存 `calculatePrice_A` が全グリッドで出力するプラン構成を抽出・正規化したもの。
最安エンジンは「この文法に沿う構成の中で、対象ランクの料金が最小になるもの」を選ぶ。

## 文法（要約）

```
予約 = [前延長] ( 基本ブロック [延長] )+
基本ブロック ∈ { ショート, 深夜休憩, 休憩, サービスタイム1〜3部, 宿泊1〜2部 }
```

### ブロックごとの制約
- **ショート**: 6:00〜翌2:00 にIN、90分被覆。延長可。
- **深夜休憩**: 23:00〜翌6:00 にIN、最大3時間。3h超は不可（宿泊へ）→ 予約全体を覆える時のみ採用。
- **休憩(プレーン)**: 平日5h／土日祝4h被覆。ただし**翌2:00で打ち切り**。
- **サービスタイム1〜3部**: 各部の枠内にIN、枠終了まで被覆。平日と土日祝で枠が異なる。
- **宿泊1〜2部**: 保証チェックアウトまで被覆（12h保証＝日〜金祝／10h保証＝土・祝前日・連休）。
- **延長**: 30分単位・切り上げ。ブロックの後、または先頭（前延長）に付く。
- 各ブロックは時系列順。被覆の隙間・はみ出しは延長で埋める。少なくとも1ブロック必要。

## 使い方（最安エンジン）

入力 (rank, チェックイン時刻, 利用時間, 曜日区分) に対し、上記文法に沿って成立する全構成を列挙し、
**対象ランクの料金表で合計が最小**になる構成を返す。ランクAで `calculatePrice_A` と一致することを
回帰テストで担保し、一致が取れたら他ランク・他区分へそのまま適用する。
